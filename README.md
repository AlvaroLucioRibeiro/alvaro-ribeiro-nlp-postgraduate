# Processamento de Linguagem Natural (PLN)

Este repositório reúne materiais acadêmicos, atividades práticas e notebooks Jupyter da minha **pós-graduação em Processamento de Linguagem Natural (PLN)** no **AKCIT**.

O objetivo é explorar os fundamentos teóricos e as aplicações de PLN, combinando aprendizado de máquina, aprendizado profundo e modelos de linguagem para desenvolver sistemas capazes de compreender, processar e gerar linguagem humana.

O repositório também serve para registrar o aprendizado e organizar os materiais de estudo, experimentos e projetos desenvolvidos ao longo do curso.

## Como usar os materiais

1. Acesse a pasta do módulo que deseja estudar.
2. Consulte o livro (`ModuleN_EBook.pdf`) e o resumo (`ModuleN_Resume.pdf`), em que `N` corresponde ao número do módulo.
3. No módulo 2, abra os arquivos `.ipynb` no Jupyter Notebook, JupyterLab ou Google Colab para executar as atividades. O GitHub também permite visualizar os notebooks.
4. Antes de executar um notebook, confira as instruções e importações nas células para identificar as bibliotecas necessárias.

Os materiais estão organizados por módulo, sem um ponto único de execução. Cada notebook pode ser aberto individualmente no ambiente escolhido.
